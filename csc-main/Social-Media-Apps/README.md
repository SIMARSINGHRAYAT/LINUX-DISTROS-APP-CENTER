# Social Media Apps

These Debian launchers use Chromium or Google Chrome app mode with an isolated, persistent profile and the provided official logo for each service. Sign in or create an account in the official website window after installation; the profile is retained for future launches.

- [WhatsApp](WhatsApp/README.md)
- [Telegram](Telegram/README.md)
- [Instagram](Instagram/README.md)
- [LinkedIn](LinkedIn/README.md)
- [Snapchat](Snapchat/README.md)
- [Facebook](Facebook/README.md)
