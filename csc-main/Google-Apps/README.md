# Google Apps Desktop Hub

## Debian Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/Google-Apps/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

## Debian Uninstallation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/Google-Apps/uninstall.sh | LINUX_DESKTOP_DISTRO=debian bash
```

The hub provides Gmail, YouTube, Google Photos, Google Meet, YouTube Music, Google Analytics, Google Ads, Maps, Google One, Docs, Slides, Sheets, Calendar, Google Search, and Gemini in one persistent desktop window.
