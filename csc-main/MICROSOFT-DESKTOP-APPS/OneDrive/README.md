# Microsoft OneDrive Desktop

The Debian and Ubuntu packages open OneDrive from Microsoft 365 and keep its Microsoft sign-in session between launches. Uninstalling removes its local session and settings, but does not delete downloaded files or data in your Microsoft account.

## Debian installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/OneDrive/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

## Debian uninstallation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/OneDrive/uninstall.sh | LINUX_DESKTOP_DISTRO=debian bash
```

## Ubuntu installation and uninstallation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/OneDrive/install.sh | LINUX_DESKTOP_DISTRO=ubuntu bash
```
