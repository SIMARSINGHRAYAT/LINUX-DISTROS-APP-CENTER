# Microsoft Power Automate Desktop

The Debian package opens the official Power Automate portal and keeps its Microsoft sign-in session between launches.

## Debian installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/PowerAutomate/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

## Debian uninstallation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/PowerAutomate/uninstall.sh | LINUX_DESKTOP_DISTRO=debian bash
```
