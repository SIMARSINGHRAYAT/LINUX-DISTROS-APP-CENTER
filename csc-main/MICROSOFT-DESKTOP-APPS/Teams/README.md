# Microsoft Teams Desktop

## Ubuntu Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Teams/install.sh | LINUX_DESKTOP_DISTRO=ubuntu bash
```

## Debian Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Teams/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

The installer builds and installs a native Debian `.deb` package. Sign in or create a Microsoft account from the official Teams sign-in page; the session is retained between launches.
