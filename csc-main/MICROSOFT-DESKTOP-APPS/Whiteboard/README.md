# Microsoft Whiteboard Desktop

## Ubuntu Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Whiteboard/install.sh | LINUX_DESKTOP_DISTRO=ubuntu bash
```

## Debian Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Whiteboard/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

The installer builds and installs a native Debian `.deb` package. Sign in or create a Microsoft account from the official Whiteboard sign-in page; the session is retained between launches.

The desktop wrapper keeps Whiteboard authentication and its required Microsoft Office service redirects inside the app session. If an older build remains installed, uninstall it and reinstall with the commands below.
