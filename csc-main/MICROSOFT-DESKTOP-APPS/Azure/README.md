# Microsoft Azure

Access Microsoft Azure through the official portal:

[Open Microsoft Azure](https://portal.azure.com)

## Ubuntu Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Azure/install.sh | LINUX_DESKTOP_DISTRO=ubuntu bash
```

## Debian Installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Azure/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

The installer builds and installs a native Debian `.deb` package. Sign in or create a Microsoft account from the official Azure portal sign-in page; the session is retained between launches.
