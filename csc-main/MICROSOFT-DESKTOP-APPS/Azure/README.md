# Microsoft Azure

Access Microsoft Azure through the official [Azure portal](https://portal.azure.com). The Debian and Ubuntu desktop packages keep their Microsoft sign-in session between launches. Uninstalling removes the local session and settings, but does not delete downloaded files or data in your Microsoft account.

## Debian installation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Azure/install.sh | LINUX_DESKTOP_DISTRO=debian bash
```

## Debian uninstallation

```bash
curl -fsSL https://github.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/raw/refs/heads/main/csc-main/MICROSOFT-DESKTOP-APPS/Azure/uninstall.sh | LINUX_DESKTOP_DISTRO=debian bash
```
